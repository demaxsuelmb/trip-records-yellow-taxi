# Failure log

One entry per failure experiment (see [`PLAN.md`](PLAN.md)).

## Template

### M<n> — <short name>
- **Symptom:** the error message or wrong result, as seen.
- **Root cause:** why it happens (engine behavior, not just "it was wrong").
- **Fix:** what changed.
- **Prevention:** test, check or design rule that stops it from coming back.
