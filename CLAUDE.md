# Instructions for Claude in this repo

This is a hands-on learning project. The author writes the code.

- **Do not write the solution.** Explain concepts, point at the line that is wrong, ask guiding questions,
  and review code after it is written. Write code only when explicitly asked for a specific snippet.
- When an error appears, ask what the message says before explaining it.
- Follow `docs/PLAN.md`: one module at a time, each with its failure experiment recorded in `docs/FAILURES.md`.
- Public data only. Never commit credentials, tokens or data files.
- Conversation in Brazilian Portuguese; code, comments and docs in English.
